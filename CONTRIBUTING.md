# Contributing

AI Compact contains a reusable framework and Andrew Allen's real personal implementation. Contributions are welcome where they improve the generic framework, identify an internal inconsistency, repair documentation or add evidence about behaviour across AI products.

The personal kit remains owner-maintained. A proposed change to `kit/` should explain the observed failure or new requirement it addresses; personal preference alone is not a reason to change someone else's kit.

Before opening a pull request:

1. Open an issue for a structural or high-authority change.
2. Keep personal material out of `framework/`.
3. Update the source layer before any derived platform adapter.
4. Add or update eval fixtures when behaviour changes.
5. Use relative Markdown links and keep navigation repository-name-neutral.
6. Run link validation, `git diff --check` and a privacy/secret scan.

Do not include credentials, private contact details, customer information, raw conversations or personal data about third parties.
