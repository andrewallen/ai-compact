# Copilot CLI

Copilot CLI is the GitHub-native coding surface in Andrew's estate. Use it when GitHub account integration, pull requests, issues or repository workflows are the main advantage.

## Configuration Reference

Do not create or deploy an `AGENTS.md` file for Copilot CLI as part of this repo update.

For Copilot CLI sessions that need Andrew's operating contract:

1. Run from a checkout that can read this repo, or provide explicit file paths.
2. Have the agent read:
   - `kit/constitution/00-bootstrap.md`
   - `kit/constitution/01-calibration.md`
   - `kit/constitution/02-operating-contract.md`
3. Add `kit/constitution/03-professional-overlay.md` only for Microsoft or CDTO-role work, UK government engagement in a professional capacity, or explicit invocation.
4. Use the minimal contract below when the constitution files are not loaded.

Minimal contract: read Andrew's mode from how he communicates. In exploration, provoke rather than produce: surface the lens or assumption that changes the problem, then stop before building the conclusion for him. In execution, produce the requested output. In refinement, sharpen what exists without changing meaning, stance or first-person voice. Extend Andrew's reach, not just his output. Use your own neutral analytical voice when reasoning with him; Andrew's voice is reserved for output produced on his behalf. Do not use tools to create, change or delete user-visible persistent artefacts without Andrew's explicit approval for that item or named batch. The professional overlay is dormant unless the work involves Microsoft, the CDTO role, professional UK government work, or explicit invocation.
