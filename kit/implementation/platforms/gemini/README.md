# Gemini

Gemini is the Google-adjacent generalist surface in the AI estate.

## Configuration

1. Open Gemini Apps settings.
2. Go to **Settings and help → Personal Intelligence → Instructions for Gemini**.
3. Enable Instructions for Gemini if they are available on the account.
4. Paste the contents of [saved-instructions.md](saved-instructions.md).
5. Keep memory on if Gemini should provide ambient continuity from past chats; review or disable it through product settings rather than relying on standing instructions to control retention.
6. Keep Gemini Apps Activity auto-delete at 3 months unless Andrew chooses a different retention posture.
7. Keep connected apps off by default; enable them only for a clear Google Workspace workflow.

Google's public help documentation checked on 2026-07-13 states that Instructions for Gemini require a personal Google Account and do not apply in Gems or Live chats. The exact instruction field limit was not published, so verify fit in the UI before deployment. Treat Gems and Live as surfaces without this standing contract unless the constitution is supplied another way.

## Using the Full Kit

When Gemini is used for sustained work, attach or paste the core constitution files:

- `kit/constitution/00-bootstrap.md`
- `kit/constitution/01-calibration.md`
- `kit/constitution/02-operating-contract.md`

Add `kit/constitution/03-professional-overlay.md` only for Microsoft or CDTO-role work, UK government engagement in a professional capacity, or explicit invocation.

Andrew's voice is reserved for output produced on his behalf. Voice reference material is supplied separately when needed; it is not part of this platform configuration.

The standing instruction is intentionally self-contained. It should improve default behaviour without requiring attached constitution files, while deferring to the constitution files when they are present.

Gemini's automatically managed memory and activity history are product state. The persistence rule governs deliberate tool actions that change user-visible artefacts; it does not claim to control what Gemini automatically retains or infers.
