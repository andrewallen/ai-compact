# Grok

Andrew mainly uses Grok for execution. Use the [execution contract](../execution-contract.md) with the established task decisions, or supply the [core constitution](../../../constitution/README.md) for broader thinking work. The personal voice boundary and approval requirements are the same.

This is deployment guidance, not a record of installed settings. No Grok account, app, API or agent configuration was inspected or changed during the September alignment review.

## Apply through the actual host

Identify whether the task runs in the Grok app, an xAI agent or a gateway such as OpenCode Go. Supply the contract through the instruction mechanism that the actual surface supports; inspect that mechanism before replacing existing instructions. A reference to a local file is not proof the host can read it.

Use [model guidance](../model-guidance.md) for the documented Grok 4.6 details. Do not assume native search, code execution, memory or permission behaviour carries through a gateway. A request to prepare work is distinct from permission to send or publish it.
