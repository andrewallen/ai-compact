# OpenCode and Go

Use the [execution contract](../execution-contract.md) and a concrete task handover for delegated work. The [core constitution](../../../constitution/README.md) remains available for broader work. Go is a model-access offering; see [model guidance](../model-guidance.md) for the distinction between subscription, model and host.

## Instruction composition

The [OpenCode v2 agent documentation](https://opencode.ai/v2/docs/agents), checked 13 September 2026, says a non-empty custom agent `system` replaces that agent's provider base prompt. Project instructions, skills and references are still added. Permissions are separate controls.

Before deploying, confirm the installed OpenCode version and how that version combines instructions. Preserve useful provider instructions when adding the compact. Do not paste the full constitution into an agent override on the assumption that the operation is additive. No config file or global instruction file is created by this reference.
