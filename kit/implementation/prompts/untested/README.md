# Experimental Prompts

Candidate prompts available for deliberate trials. The folder name records their evidence status, not a backlog: inclusion creates no commitment to test or promote a prompt. A prompt moves to the parent folder only after it works in practice and its wording has been adjusted from evidence rather than expectation.

| Prompt | Intended use |
|---|---|
| [Advisory synthesis](advisory-synthesis.md) | Turn multiple sources into an evidence-weighted recommendation. |
| [Analytical decomposition](analytical-decomposition.md) | Separate a complex analysis into interacting dimensions. |
| [Blind-spot questions](blind-spot-questions.md) | Surface questions a domain expert would ask without supplying the answers. |
| [Investigative brief](investigative-brief.md) | Stage background research, confidence and fact checking. |
| [Multi-perspective exploration](multi-perspective-exploration.md) | Compare distinct expert lenses before forming a position. |
| [Own the synthesis](own-the-synthesis.md) | Test whether delegated analysis has been understood before use. |
| [Position development](position-development.md) | Stress-test a working thesis and its revision conditions. |
| [Structured critique](structured-critique.md) | Evaluate a document or argument against direct evidence. |
| [Task decomposition](task-decomposition.md) | Design a staged reasoning approach before execution. |
| [Variations for reaction](variations-for-reaction.md) | Use disposable alternatives to elicit a direction. |
| [What good looks like](what-good-looks-like.md) | Learn an unfamiliar domain's evaluative standard before judging work. |

The lifecycle and promotion rules are defined in the [prompts index](../README.md).
