# Analytical Decomposition

**What it does.** Structures a complex analysis by breaking it into distinct dimensions, examining each with explicit confidence and counter-evidence, then identifying where dimensions interact or conflict.

**When to use it.** When the analysis involves multiple perspectives, competing considerations, or dimensions that need to be examined separately before being synthesised. Policy analysis, strategic assessment, technology evaluation, organisational diagnosis.

## Prompt

> Analyse [SUBJECT] by addressing these dimensions:
> 1. [DIMENSION_1]
> 2. [DIMENSION_2]
> 3. [DIMENSION_3]
>
> For each dimension:
> - State what you know with high confidence and what is uncertain
> - Identify the strongest evidence and the strongest counterargument
> - Note where this dimension interacts with the others
>
> Begin with a 2-sentence summary of the overall finding. Address each dimension in turn. Conclude with what this analysis changes about how we should think about [SUBJECT].

## Notes

The power is in the counter-evidence requirement. Without it, the model will build a case rather than test a hypothesis. The interaction question at the end is where non-obvious insights surface — it forces the model to look across dimensions rather than treating them as independent.

Pairs well with the expansion function — the model should bring dimensions you have not named if they are material.
