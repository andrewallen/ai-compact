## Reading the evidence

- **Recorded:** an existing repository record describes the observed setting. No fresh account inspection was performed for this matrix.
- **Exposed:** the current Codex session advertises a relevant skill or tool. This establishes discovery availability only; package parity, dependencies and task quality remain untested.
- **Candidate:** a possible provider for evaluation, not a deployed capability.
- **Unknown:** insufficient evidence. It does not mean unsupported or absent.

A built-in capability can fill a cell even when its implementation is not inspectable. A public vendor skill is not assumed identical to a client-bundled implementation. Model, client, enabled package, loaded instructions and successful execution are separate observations. There are no locally validated comparative winners in this initial matrix.
