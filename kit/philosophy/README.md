# Philosophy

Layer 1 of the personal kit: the axioms that state why intelligence is in the system and what must not be optimised away.

| File | Purpose |
|---|---|
| [axioms.md](axioms.md) | The ten maintenance-time axioms from which the constitution derives. |

The philosophy is background, not runtime instruction. It is loaded deliberately only when the foundations themselves are being reviewed. If an axiom changes, review the [constitution](../constitution/README.md), its derived platform prompts and the relevant [evals](../evals/README.md).

The generic rule for this layer is defined in the [framework layer model](../../framework/layer-model.md). The personal decision to keep philosophy out of runtime context is recorded in [ADR-002](../../governance/decisions/adr-002-philosophy-is-background.md).
